BETA

Write TypeScript. Ship it. Install nothing else.

Mokou is a fast, secure runtime for JavaScript and TypeScript. SQLite, S3, Markdown, tar archives and a terminal are already inside, so your project starts with code instead of a dependency list.

Get MokouEarly beta · build from source Take the tour

Built on V8 and Rust. Runs your existing Deno programs unchanged.

server.ts — mokou
// server.ts
using db = Mokou.openSqlite("app.db");
db.exec("CREATE TABLE IF NOT EXISTS hits (n)");

Mokou.serve(() => {
  db.run("INSERT INTO hits VALUES (1)");
  const n = db.query("SELECT count(*) AS n FROM hits");
  return new Response(`Hello! Visit #${n[0].n}`);
});

$ mokou run --unstable-sqlite -A server.ts
Listening on http://localhost:8000/
100% TypeScript Secure by default MIT licensed V8 + Rust 0 dependencies to start

Why people will like Mokou

Secure by default

A program can't read your files, open a socket or run a command until you say so. Even your keychain needs its own permission.

Batteries included

Passwords, SQLite, S3, routing, Markdown, tar, CSRF tokens, test mocks and more are part of the runtime. No install, no lockfile.

Fast and native

Common jobs run in Rust instead of JavaScript. We benchmark against Deno, Node and Bun and keep the numbers in the repository, so you can check them.

Take the tour

const s3 = new Mokou.S3Client({ bucket: "photos" });

await s3.write("hello.txt", "Hello from Mokou!");
console.log(await s3.file("hello.txt").text());

// A link that works for an hour, signed on your machine.
console.log(s3.presign("hello.txt", { expiresIn: 3600 }));

Works with Amazon S3, Cloudflare R2 and MinIO. Run with --unstable-s3.

const html = Mokou.markdown.html("# Hello *world*");
// "<h1>Hello <em>world</em></h1>\n"

// Raw HTML in untrusted text is dropped for you.
Mokou.markdown.html("<script>steal()</script>");

// And a one-liner for plain text going into a page.
Mokou.escapeHTML(`<b>Tom & Jerry</b>`);

Tables, task lists and strikethrough work out of the box. Run with --unstable-html.

const archive = await Mokou.tar.create({
  "README.md": "# Hello",
  "data/config.json": JSON.stringify({ a: 1 }),
}, { gzip: true });

await Mokou.writeFile("out.tar.gz", archive);
await Mokou.tar.extract(archive, "./out");

Extracting never writes outside the folder you choose. Run with --unstable-tar.

const pty = Mokou.spawnPty("bash", { cols: 100, rows: 30 });

pty.readable.pipeTo(Mokou.stdout.writable);
await pty.write("ls --color\n");
await pty.write("exit\n");
await pty.status;

Run interactive programs the way a real terminal does. Linux and macOS for now. Run with --unstable-pty.

const hash = await Mokou.password.hash("hunter2");

console.log(await Mokou.password.verify("hunter2", hash)); // true
console.log(await Mokou.password.verify("letmein", hash)); // false

Argon2id by default, computed off the main thread. Run with --unstable-password.

Get Mokou

Mokou is in early beta and has no downloadable release yet. Until the first one, build it from source. You need Rust and the usual build tools.

Once releases start, mokou upgrade will fetch them from our own releases page. The program installs as mokou, with deno kept as an alias, so your scripts and CI steps keep working.

Get the sourcegithub.com/weeabo-inc/done
Terminal
$ git clone --recurse-submodules \
    https://github.com/weeabo-inc/done.git
$ cd done
$ cargo build --bin deno
$ ./target/debug/deno eval \
    'console.log("Hello from Mokou")'
Hello from Mokou
